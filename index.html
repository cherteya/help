Добавить фильм от имени зрителя в обход баллов канала! Указываем @ник! Можно добавлять по названию (с годом или без) или прямыми ссылками.

По названию (без года): !fz @Зритель Шрек (add)

По названию (с годом при совпадениях): !fz @Зритель Шрек 2001 (add)

По ссылке TMDB: !fz @Зритель https://www.themoviedb.org/movie/808 (add)

По ссылке Кинопоиска: !fz @Зритель https://www.kinopoisk.ru/film/430/ (add)
Алиасы: (заказ, добавить, доб, order, add)

🔄 Повторный ввод отменит статус аукциона!
По названию (без года): !fz @Зритель Бойцовский клуб (аук)

2. Управление Статусами

Статус: В процессе
Устанавливает статус фильма на «Смотрим».
Пример команды: !fz Шрек (смотрим)
Алиасы: (смотрим, watching)
Статус: Просмотрено (Без оценки)
Закрывает заказ и переносит в архив. Если ввести еще раз — вернет в очередь.
Пример команды: !fz Шрек (смотрели)
Алиасы: (смотрели, watched, смотрел, смотрела)
Статус: Оценка и Золото
Закрывает заказ с выставлением оценки (цифрами). Оценка (1000) выдает Золотой Статус.
Обычная оценка: !fz Шрек (8.5)

Золотой статус: !fz Шрек (1000)

3. Прикрепление Медиа и Ссылок

Добавить Постер
Привязывает свою картинку/обложку к заказу. Ссылка пишется внутри скобок через пробел.

🗑️ Если написать просто (постер) без ссылки, свой постер будет удален!
Пример команды: !fz Шрек (постер https://ссылка.jpg)
Алиасы: (постер, poster, картинка, обложка)
Добавить пост Telegram
Привязывает пост с отзывом/анонсом в вашем ТГ. Можно указывать как номер поста, так и полную ссылку.

🗑️ Если написать просто (тг) без номера или ссылки, привязка будет удалена!
По номеру поста: !fz Шрек (тг 122)

По полной ссылке: !fz Шрек (тг https://t.me/sarachuma/122)
Алиасы: (пост, post, tg, тг)
Многосерийные записи (Части 1, 2, 3...)
Если прохождение/просмотр занял несколько стримов, добавляйте записи с помощью цифр. Можно использовать полные ссылки или номера постов. Первая часть пишется как обычно, остальные — с цифрой без пробела.

🗑️ Чтобы удалить конкретную часть, напишите алиас с цифрой без ссылки.
Первая часть (по номеру или ссылке): !fz Шрек (тгзапись 122)
!fz Шрек (ютуб https://...)

Вторая и третья части: !fz Шрек (тгзапись2 123)
!fz Шрек (ютуб3 https://...)

Удалить вторую часть ТГ: !fz Шрек (тгзапись2)
Алиасы: (тгзапись, бусти, ютуб) + цифра
Привязка Кинопоиска (Для кнопки)
Добавляет на сайт кнопку «Смотреть онлайн», если она не появилась. Можно указать ID или полную ссылку.
По ID Кинопоиска: !fz Шрек (кп 430)

По ссылке: !fz Шрек (кп https://www.kinopoisk.ru/...)
Алиасы: (кинопоиск, kinopoisk, kp, кп)
Включить/Выключить «Смотреть онлайн»
Команда, которая переключает отображение кнопок «Смотреть онлайн» для зрителей на сайте.
Переключатель: !fz (онлайн)
Алиасы: (online, онлайн)
