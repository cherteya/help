Руководство по управлению

👑 Для Стримера и Модераторов

Главная команда в примерах: !заказ (подставьте свою: !filmzakaz, !fz, !gamezakaz, !gz и т.д.).
Ручное добавление (в обход баллов)
!заказ @ник Название (add)
Добавляет заказ в очередь от имени указанного зрителя.
Алиасы: (заказ), (order), (add)
Победа на аукционе
!заказ @ник Название (аукцион)
Добавляет заказ со статусом ✦ Аукцион ✦.
Алиасы: (аукцион), (auction), (аук)
Пройдено / Посмотрели с оценкой
!заказ Название (8.5)
Закрывает заказ и выставляет вашу оценку (от 0 до 10). Поддерживаются точки и запятые.
🔥 Секрет: оценка (1000) выдаст золотой статус!
Пройдено / Посмотрели (Без оценки)
!заказ Название (смотрели/прошли)
Переводит из очереди в «Смотрели/Пройдено» (без оценки).
⚠️ Если ввести эту команду повторно — заказ вернется обратно в статус «В очереди»!
Алиасы: (смотрели), (посмотрели), (watched)
Алиасы: (пройдено), (complete), (прошли)
Добавить метку «Слёзы»
!заказ Название (слёзы)
Добавляет метку 💧 для эмоциональных игр/фильмов. Работает только для просмотренных!
Алиасы: (слёзы), (плакал), (cry)
Можно комбинировать: (8.5) (слезы)
Удаление из базы
!заказ Название (удалить)
Полностью и навсегда стирает заказ зрителя из базы.
Алиасы: (удалить), (delete), (del), (убрать)
Если не может найти фильм или игру
то удаляем по нику + ID: !заказ @ник 12 (удалить)
Замена заказа
!заказ Старое [Новое]
Заменяет текущий заказ на другой (удобно, если зритель передумал). Новое название нужно писать строго в квадратных [ ] или фигурных { } скобках.
Пример: !заказ Начало [Шрек 2]
Принудительное обновление сайта
!заказ (обновить)
Если сайт почему-то не обновился автоматически, эта команда заставит бота отправить базу данных еще раз.
Алиасы: (обновить), (update), (refresh)
